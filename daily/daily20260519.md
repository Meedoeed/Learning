# Продолжение индивидуального задания

Сделал небольшой план по продолжению выполнения ИЗ - основная его суть - переход от монолита к микросервисам

Релиз 1 (Cobra CLI) – установка cobra, создание root command и команд backend/scheduler/worker, рефакторинг main.go под команды, тестирование всех режимов. 

Релиз 2 (Connect RPC + вынос воркеров) – настройка proto, определение схемы Task/Progress/Heartbeat, реализация RPC сервера в бэкенде и клиента в воркере, переписывание воркера на получение задач через RPC, удаление прямого доступа воркера к БД, heartbeat-механика, тестирование.

Релиз 3 (выделение шедулера) – перемещение логики планирования из бэкенда в отдельную команду, RPC-методы для шедулера (GetServers, CreateTasks), синхронизация шедулера для исключения дублирования задач, удаление планировщика из бэкенда, тестирование.

Релиз 4 (отказоустойчивость) – обработка падения воркеров (таймауты, перераспределение задач), graceful shutdown для всех компонентов, метрики для мониторинга (количество воркеров, задачи в очереди), тестирование отказоустойчивости.
